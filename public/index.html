Cursor Meter

Polls Cursor’s dashboard JSON from a tiny local Node server, then shows live-ish spend, token totals, models, and recent expensive requests.

Credential
Checking…
Security note: your Cursor session token is effectively a bearer credential. This page talks only to localhost. Do not deploy this app, do not bind it to a public interface, and do not commit .env.

Token setup

Best path: put CURSOR_SESSION_TOKEN in .env. This form is disabled unless ALLOW_TOKEN_FROM_UI=true; when enabled, the backend keeps the token in memory only.

Where to get it
  1. Open https://cursor.com/dashboard/usage while logged in.
  2. Open DevTools → Application → Cookies → https://cursor.com.
  3. Copy WorkosCursorSessionToken.
  4. Paste here or save as CURSOR_SESSION_TOKEN in .env.
